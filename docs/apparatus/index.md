# Apparatus

The instruments, not the argument. Everything here exists to make the rest of
the site addressable, quotable, and searchable.

- **[Epigraph Concordance](epigraphs.md)** — every borrowed line, filed by
  writer, each with a permanent anchor. Generated from the manuscript.
- **[Lexicon](lexicon.md)** — terms used here in a particular sense. Binding on
  the rest of the site.
- **[Toolshed](toolshed.md)** — the machinery. Generated from a source table.

## What is generated and what is written

| Page | Source | Editable by hand? |
|---|---|---|
| Epigraph Concordance | the collected drafts PDF | No — rebuild it |
| Toolshed | `data/links.csv` | No — edit the table |
| Lexicon | itself | Yes |
